# 1PS-and-More
Combined pack using player.json, including:
1. One Player Sleep system (This sends a message in chat for sleeping players, a good morning notice, makes sure sleeppercent is at 0, and resets the weather)
2. Hours Played counter (Counts number of hours played, as long as player is not AFK)
3. Biome display (when a compass is held in hand)
4. Rider speed display (shows rideable mob speed when a compass is held in hand while riding the mob)
5. Mob spawners and budding amethyst will drop when broken
6. /tospawn Command (Teleports players to 0, 100, 0 in the overworld on-run)
7. /gms and /survival commands (Sets players to survival gamemode); /gmsp and /spectator commands (Sets players to spectator gamemode). Plus OP-only /gmc and /creative commands.
8. Death Counter Scoreboard (Scoreboard ID "deaths"), originally by RavinMadHatter
9. AFK Display (Sets players to AFK after 5 minutes, scoreboard ID afk_display), originally by DrAv
10. Ding! sound when a player hits another entity with an arrow or firework rocket from a bow or crossbow.
#### Please note: When you add this addon for the first time, you must run "/function initialize" to add the scoreboards. This addon does not disable achievements.
